# Customer Churn Analysis

## Project Overview

This project analyzes customer churn behavior using Python and Machine Learning techniques to identify factors affecting customer retention.

---

## Business Objective

The objective of this project is to:

* Analyze customer behavior patterns
* Identify major churn-driving factors
* Build predictive machine learning models
* Generate retention-focused business recommendations

---

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

---

## Dataset Information

The dataset contains customer demographic, billing, subscription, and service-related information used for churn analysis.

### Key Features

* Customer ID
* Gender
* Contract Type
* Monthly Charges
* Tenure
* Payment Method
* Churn Status

---

## Exploratory Data Analysis

The project includes:

* Churn distribution analysis
* Contract type analysis
* Monthly charges analysis
* Tenure analysis
* Correlation analysis

---

## Machine Learning Models

Implemented Models:

* Logistic Regression
* Random Forest Classifier

---

## Key Insights

* Customers with month-to-month contracts showed higher churn probability.
* Higher monthly charges were associated with increased churn risk.
* Customers with shorter tenure were more likely to churn.

---

## Business Recommendations

* Introduce loyalty programs for new customers.
* Encourage long-term subscription plans.
* Improve retention campaigns for high-risk customers.
